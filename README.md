Rentix: Sistema de Administración de Comunidades y Gastos Comunes

Rentix es una plataforma web centralizada diseñada para optimizar la gestión administrativa de comunidades residenciales. El sistema permite digitalizar y automatizar procesos clave —como el registro de residentes, cálculo de gastos comunes y control de morosidad— para reducir errores humanos, mejorar la transparencia financiera y facilitar la comunicación dentro del edificio.

Este proyecto fue desarrollado bajo una metodología tradicional (modelo en cascada).

Características Principales

Gestión Administrativa: Registro y control centralizado de residentes y unidades habitacionales.

Gestión Financiera: Automatización del cálculo de cuotas de gastos comunes y control automático de morosidad.

Comunicación: Sistema de notificaciones automáticas y centralización de solicitudes y reclamos.

Reportería: Generación de informes financieros y operativos en tiempo real.

Arquitectura
El sistema adopta un estilo monolítico por capas y aplica el patrón de diseño Modelo Vista Controlador (MVC), garantizando una alta cohesión y bajo acoplamiento. La estructura se fundamenta en el Modelo 4+1, que organiza el sistema en vistas estratégicas para asegurar escalabilidad y mantenibilidad.

Tecnologías y Metodología

Herramientas: Figma para prototipado interactivo.

Modelado: Lenguaje UML para diagramas de clases, componentes, despliegue y otros.

Metodología: Modelo tradicional en cascada con una duración planificada de 32 semanas y un presupuesto de $54.000.000.
